# Samples

`offline_demo/` was produced with `--offline`: saved drafts replayed through the real loop and a rule-based judge.
It shows the SHAPE of the outputs (lesson, rejection log). It is NOT the submission lesson.
Run `python -m lessonforge run` with an API key to generate the real one.

I used an AI assistant (Claude) to help design and write the code. I ran it myself with Gemini, debugged the errors, reviewed the generated lesson, and can explain every part of the design. The files in `samples/real_run` come from my own real run.
